# MOV+

واجهة Web عربية مستقلة لكتالوج الأفلام والمسلسلات، مبنية لتعمل على GitHub Pages مع تحديث آلي للبيانات.

## المزايا الحالية

- واجهة RTL متجاوبة للموبايل والكمبيوتر.
- صفحات رئيسية للأفلام والمسلسلات.
- بحث محلي سريع.
- فلترة حسب النوع والسنة والترتيب.
- صفحات تفاصيل مع التقييم والوصف والأنواع والممثلين والتريلرات.
- مواسم المسلسلات.
- التوفر حسب البلد ومزوّدي المشاهدة الرسميين عندما تتوفر بياناتهم.
- مفضلة محفوظة محلياً على جهاز المستخدم.
- PWA manifest لإضافة الموقع للشاشة الرئيسية.
- كتالوج يتحدث يومياً عبر GitHub Actions.
- تفاصيل موسعة محفوظة في `data/details`.
- لا يوجد TMDB API key داخل JavaScript الذي يصل للزائر.

## التشغيل

1. أضف Secret باسم `TMDB_API_KEY` من `Settings → Secrets and variables → Actions`.
2. من `Settings → Pages` اختر النشر عبر `GitHub Actions`.
3. شغّل `Sync catalog` يدوياً أول مرة.
4. بعد نجاح المزامنة، Workflow النشر يحدّث GitHub Pages تلقائياً.

## TMDB

هذا المنتج يستخدم TMDB API لكنه غير معتمد أو موصى به من TMDB. بيانات التوفر لمزوّدي المشاهدة مصدرها TMDB/JustWatch عندما تكون متاحة.

للاستخدام التجاري يجب مراجعة شروط وترخيص TMDB المناسب للمشروع. للاستخدام غير التجاري يجب الالتزام بمتطلبات الإسناد والعلامة التجارية الخاصة بـTMDB.

## المشاهدة

المشروع الحالي كتالوج وواجهة اكتشاف، وليس مستودعاً لروابط بث غير مصرّح بها. أي زر مشاهدة أو مصدر فيديو مستقبلي يجب أن يشير إلى مصدر تملك حق استخدامه أو إلى مزوّد رسمي.

## التقنية

HTML + CSS + JavaScript خفيف، GitHub Pages، GitHub Actions، وTMDB API للبيانات الوصفية.
