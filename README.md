# MOV+

واجهة Web عربية مستقلة لكتالوج الأفلام والمسلسلات والأنمي، مبنية لتعمل على GitHub Pages مع تحديث آلي للبيانات.

## المزايا

- واجهة RTL متجاوبة للموبايل والكمبيوتر.
- أقسام أفلام ومسلسلات وأنمي.
- كتالوج كبير متعدد المصادر مع إزالة التكرار.
- بحث موحّد عبر الأفلام والمسلسلات والأنمي.
- ترتيب حسب الشعبية والتقييم وتاريخ الإصدار.
- صفحات تفاصيل تشمل الوصف والأنواع والتقييم والممثلين والتريلرات.
- مواسم وحلقات TV مع الصور والوصف وتاريخ العرض والتقييم.
- توفر المشاهدة الرسمية حسب البلد عندما تتوفر بيانات المزود.
- روابط المواقع الرسمية للمحتوى.
- مفضلة محفوظة محلياً على جهاز المستخدم.
- PWA manifest لإضافة الموقع للشاشة الرئيسية.
- مزامنة يومية عبر GitHub Actions.
- تفاصيل موسعة محفوظة محلياً داخل المستودع حتى لا يحتاج الزائر إلى مفتاح API.

## مصادر البيانات

- TMDB للبيانات الوصفية للأفلام والمسلسلات والتقييمات والمواسم والمزودين.
- Jikan / MyAnimeList لكتالوج الأنمي وبياناته.
- YouTube للتريلرات المضمّنة عندما يكون الفيديو قابلاً للتضمين.
- مزودو المشاهدة الرسميون عبر بيانات TMDB/JustWatch عند توفرها.

يمكن إضافة أي API أو مصدر فيديو مستقبلاً فقط عندما تكون شروط استخدامه وترخيص المحتوى تسمح بذلك.

## التشغيل

1. أضف Secret باسم `TMDB_API_KEY` من `Settings → Secrets and variables → Actions`.
2. من `Settings → Pages` اختر النشر عبر `GitHub Actions`.
3. شغّل `Sync catalog` يدوياً أول مرة، وبعد تغييرات مزامنة البيانات يتم تشغيله تلقائياً.
4. بعد نجاح المزامنة، Workflow النشر يحدّث GitHub Pages تلقائياً.

## البنية

```text
data/catalog.json              الكتالوج الرئيسي
data/details/                  تفاصيل الأفلام والمسلسلات
data/seasons/                  بيانات المواسم والحلقات
data/anime-details/            تفاصيل الأنمي
scripts/sync-tmdb.mjs          جامع ومحدّث البيانات
.github/workflows/             المزامنة والنشر
assets/                        الواجهة والمنطق والتصميم
```

## TMDB

هذا المنتج يستخدم TMDB API لكنه غير معتمد أو موصى به من TMDB. بيانات توفر مزودي المشاهدة مصدرها TMDB/JustWatch عندما تكون متاحة.

للاستخدام التجاري يجب مراجعة شروط وترخيص TMDB المناسب للمشروع والالتزام بمتطلبات الإسناد والعلامة التجارية.

## المشاهدة

المشروع مصمم ليكون منصة اكتشاف وتشغيل لمصادر **مصرح بها**. لا يتم تخزين أو إعادة نشر روابط بث محمية أو غير مصرح بها. يمكن إضافة مصادر فيديو يملك المشروع حق استخدامها من خلال Adapter مستقل دون تغيير واجهة الموقع.

## التقنية

HTML + CSS + JavaScript خفيف، GitHub Pages، GitHub Actions، TMDB API، وJikan API.
